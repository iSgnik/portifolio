# Checklist LinkedIn
1. Repositório público: GitHub > Settings > Danger Zone > Change visibility > Public.
2. LinkedIn > Perfil > Adicionar seção do perfil > Recomendado > Adicionar projetos.
3. Nome: Portfólio GitHub | Descrição: resumo do repositório | URL: link do GitHub Pages ou do repositório.
4. Opcional: adicionar o link em "Contato" e em "Destaques" (Featured).
